# Reviewer import

The reviewer import tool allows you to create reviewer accounts by uploading a CSV file.

> [!WARNING]
> This importer is site-specific. You must access the import tool from the press or journal you want it import the reviewers into.

To import reviewer accounts:

1. Download the [reviewer import template](../downloadables/reviewer-import-template.csv).
2. Enter your reviewer details, one per row.
3. If you wish to add more than one interest, you must separate them with a semicolon, as in “interest one; interest two; interest three”.
4. On the **Imports** plugin main page select **Reviewer Import** and click **Start Import**.
5. Select your CSV and, if you want you reviewers to receive a password reset notification, check that option.
6. Click **Import** to complete the process.

> [!WARNING]
> It is important that you let reviewers know before you user the password reset function as it can result in reviewers suspecting the message is spam.

> [!TIP]
> Download the [reviewer import sample](../downloadables/reviewer-import-sample.csv) CSV to see example data.
