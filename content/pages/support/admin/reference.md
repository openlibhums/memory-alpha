# Admin reference

The admin area home page lists Janeway's tables in sections. This page lists the sections in Janeway and the tables in each one, with links to the pages that use them.

Section names appear in capitals on screen, for example **CORE**. Next to each table are two links:

- **Add**  
  Opens a form to create a new record.

- **Change**  
  Opens the list of existing records.

To open a table, click its name or click **Change**. See [Navigating the admin area](./using-admin.md#navigating-admin).

> [!NOTE]
> The sections you see depend on what is installed. Some sections, such as **APC**, **Books** and **Imports**, come from plugins and appear only when those plugins are installed.
