# About

The Janeway documentation is maintained by the core team at the Open Library of Humanities.

## Contributions

We welcome contributions ranging from small edits to full pages. To get started, see our style guide and a contribution guide.

- [The documentation styleguide](../about/janeway-styleguide.md)
- [Contributing to the documentation](../about/contributing-guide.md)

## For developers

Developer docs are maintained separately, alongside the Janeway source code. See the [legacy developer documentation](https://janeway.readthedocs.io/en/latest/dev.html) on ReadTheDocs for installation and configuration instructions, or check out the newer set of [developer guides](https://github.com/openlibhums/janeway/tree/master/docs/md) in plain Markdown on GitHub.
